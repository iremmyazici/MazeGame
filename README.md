## 🎮 MazeGame – 3D Maze Game Developed with Unity

MazeGame is a 3D puzzle game project built in Unity using C#. The player controls a ball and navigates through a maze to reach a goal. The project focuses on movement control, collision handling, and basic game logic.

> ⚠️ Please note: The original Unity scene file (`MainScene.unity`) was lost, but the core logic and components — such as scripts, prefabs, and materials — are still available in the repository.

### 🧠 Project Highlights

- **PlayerController.cs** manages keyboard-based ball movement using Unity physics.
- Prefabs such as walls and goal points are included to illustrate level design structure.
- All materials, textures, and scripts are preserved for reconstruction or reuse.
- The game was built using Unity's Rigidbody and Collider systems for smooth physical interaction.


### 🚀 How to Use

Although the playable scene is not available, developers can review and reuse the assets and scripts to rebuild or extend the project from scratch.
